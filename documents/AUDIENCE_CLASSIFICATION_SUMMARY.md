# 🎭 Audience Classification - Quick Summary

## What It Is
**Theater experience categorization** for ticket booking, NOT movie filtering.

## Three Types

### 🌟 High Class
- **Theaters:** IMAX, Dolby, luxury recliners, fine dining
- **Price:** ₹800-₹2000+
- **Examples:** PVR Director's Cut, INOX Insignia

### 🎉 Celebration  
- **Theaters:** Family-friendly, party bookings, group discounts
- **Price:** ₹300-₹600
- **Examples:** PVR Playhouse, Fun Cinemas

### 🎬 Normal
- **Theaters:** Standard screens, comfortable, good value
- **Price:** ₹150-₹400
- **Examples:** Regular PVR/INOX screens

## Where It's Used
1. **Theater Search** - Filter theaters by experience type
2. **Ticket Booking** - Select venue class before booking
3. **Movie Page** - "Book Tickets" → Choose theater type → Select venue
